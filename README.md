# 灵巧手姿态拟合测评系统

面向大学生创新创业训练计划（首次立项）的**双窗口灵巧手测评演示页**：A 窗口用摄像头采集真实人手、识别 21 个关键点并解算关节角；B 窗口用同一组角度驱动一只仿真手同步运动；二者对比得出**姿态拟合度**，用于回答"这只仿真手到底能不能复现人手动作"。

在线访问：<https://edubaitech.github.io/hand-eval-demo/>

## 页面功能

| 模块 | 说明 |
|---|---|
| 窗口 A | `getUserMedia` 取摄像头画面 + MediaPipe Hands 识别 21 关键点并叠加骨架 |
| 窗口 B | 由关节角前向运动学绘制的仿真手；灰色虚线为人手目标姿态，紫色实线为仿真手实际姿态 |
| 六通道对照 | 拇指对掌角 + 五指屈曲角（MCP/PIP/DIP 三段和），实时显示两者差值与误差 |
| 拟合度 | `S = 100 × (1 − 平均关节角误差 / 90°)`，分档：优 ≥85、良 70—85、合格 60—70、不合格 <60 |
| 测评参数 | 仿真手自由度（6 DOF / 每指 1 关节的 5 DOF）、控制量化（模拟舵机角度分辨率）、平滑滤波 |
| 实验记录 | 逐条记录当前参数与分数，一键导出 CSV（含 BOM，可直接用 Excel 打开） |

## 使用方法

1. 打开页面，点「启动摄像头」，把手掌正对镜头（距离 40—60 cm）。
2. 依次做 10 个标准手势，每个保持约 2 秒；切换「6 DOF / 5 DOF」或调「控制量化」后再各测一轮。
3. 点「记录一条」逐条保存，最后「导出 CSV」得到对比数据表。
4. 没有摄像头或网络受限时，点「演示模式」即可用合成手势跑通全部流程。

## 技术说明

- 纯前端单文件，无需构建；除 MediaPipe 通过 CDN 加载外无其他外部依赖。
- 摄像头需要安全上下文（`https://` 或 `localhost`），因此请通过上面的 GitHub Pages 地址访问，不要双击本地 `index.html`。
- MediaPipe Hands 在首次加载时需联网下载模型文件；离线环境请使用「演示模式」。
- 已知限制：拇指被遮挡时关键点会跳变；手掌侧对镜头时角度解算误差增大——这两点可作为报告中的"误差来源"说明。
